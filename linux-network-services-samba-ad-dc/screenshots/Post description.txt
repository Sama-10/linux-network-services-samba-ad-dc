Project Title
Network Infrastructure Deployment with Zimbra Mail Server & Samba Active Directory

Project Description
Designed and deployed a complete Linux-based network infrastructure integrating core enterprise services including DHCP, email, directory authentication, and web hosting in a virtualized environment.

Technologies Used:

CentOS 7, Ubuntu Server 22.04, Ubuntu Desktop 25.10

Zimbra Collaboration Suite 8.8.15 (Mail Server)

Samba Active Directory Domain Controller

ISC DHCP Server

BIND9 DNS Server (Integration)

Apache HTTP Web Server

Oracle VirtualBox

Key Achievements:

Configured Zimbra mail server with domain mail.it16.local, created multiple user accounts, and demonstrated email communication via web interface

Implemented Samba AD DC with 3 Organizational Units (Admins, Staff, Students) and 3 users per OU for the domain it16.local

Deployed DHCP server with dynamic IP allocation range 192.168.16.101-200 and IP reservation for specific clients

Integrated DNS resolution using Samba's internal DNS to unify domain name resolution across all services

Published web server with HELLO NMA page (blue background) accessible from client machines

Ensured all VMs (CentOS + 2 Ubuntu clients) were in the same domain with working Kerberos authentication

Outcome: Successfully delivered a fully functional multi-service Linux network environment meeting all assignment requirements, with cross-service communication and centralized domain authentication.
